# Driver photograph attribution

See `credits.json` for every installed photograph’s photographer, original source file, image year, and licence. The same credits appear in the app’s Methods page. All original image files retain their linked individual licences. Existing source crops are identified by their source pages. Card presentation applies CSS cropping, colour treatment, and edge fading; faces are not retouched or generated. Portraits are illustrative and may predate or postdate the selected session. There is no endorsement by the subjects or photographers.

15 reviewed images are installed in this revision. Wikimedia returned HTTP 429 with `Retry-After: 600` during the remaining downloads, so the downloader stopped. Unavailable drivers use the existing initials fallback. After the cooldown, the local operator may rerun `scripts/install_portraits.py` from the project root to install the remaining reviewed sources. No background downloader is running.
