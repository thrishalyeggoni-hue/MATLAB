# F1 Driver DNA frontend

React + TypeScript + Vite, with Plotly charts, Lucide icons, and an SVG track replay.

See the [project README](../README.md) for data-source setup, backend commands, eligibility rules, and verification.

```bash
npm ci
npm run dev
npm run build
npm test
```

The dev server runs on port 5174 and proxies `/api` to FastAPI at port 8000.
